# Sakura AI Engine for VS Code

**さくらのAI Engine を VS Code Copilot Chat で。**

この拡張機能はコミュニティによって開発された非公式の拡張機能です。利用は自己責任でお願いいたします。

この拡張機能は、[さくらのAI Engine](https://ai.sakura.ad.jp/sakura-ai/ai-engine/) を VS Code の Copilot Chat モデルプロバイダーとして統合します。API キーを設定するだけで、さくらのAI Engine のモデルを Copilot Chat で利用できるようになります。

## 機能

- **さくらのAI Engine のモデルを Copilot Chat で利用**: モデルピッカーからモデルを選択し、コード生成やリファクタリングを依頼できます。
- **Copilot Chat の機能に対応**: 
  - **画像認識 (Vision)**: スクリーンショットや設計図をチャットに貼り付けて相談。
  - **ツール呼び出し (Tool Use)**: ファイル操作やターミナル実行を AI が自動で行うエージェント機能。
  - **Web 検索 & 推論 (Responses API)**: Web 情報に基づいた回答や、高度な推論。
- **ワークスペースをコンテキストに活用 (RAG)**: ローカルコードをインデックス化し、プロジェクトの文脈を考慮した回答を得られます。
- **使用量の可視化**: 使用したトークン数と推定コストをステータスバーに表示します。

## クイックスタート

1. **インストール**: VS Code マーケットプレイスからインストール。
2. **API キー設定**: コマンドパレット (`Ctrl+Shift+P` / `Cmd+Shift+P`) で **Sakura AI Engine: API キーを設定** を実行し、トークンを入力。
3. **モデル選択**: Copilot Chat のモデルピッカーから `Sakura AI Engine` のモデルを選択。
4. **利用開始**: チャットで質問や指示を入力してください。
