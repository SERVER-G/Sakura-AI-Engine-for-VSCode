# Sakura AI Engine for VS Code

**さくらのAI Engine を VS Code Copilot Chat で。**

この拡張機能は、[さくらのAI Engine](https://www.sakura.ad.jp/ai-engine/) を VS Code の Copilot Chat モデルプロバイダーとして統合します。API キーを設定するだけで、最高性能の LLM を VS Code のエディタ体験にシームレスに組み込むことができます。

## 🚀 このプラグインでできること

- **最高峰のモデルを Copilot Chat で利用**: モデルピッカーから Sakura AI Engine のモデルを選択し、コード生成やリファクタリングを依頼できます。
- **最新の AI 機能に完全対応**: 
  - **画像認識 (Vision)**: スクリーンショットや設計図をチャットに貼り付けて相談。
  - **ツール呼び出し (Tool Use)**: ファイル操作やターミナル実行を AI が自動で行うエージェント機能。
  - **Web 検索 & 推論 (Responses API)**: 最新の Web 情報に基づいた回答や、高度な思考プロセスを伴う推論。
- **ワークスペースを賢く活用 (RAG)**: ローカルコードをインデックス化し、プロジェクト全体を理解した上での回答を実現。
- **コストと使用量の可視化**: 使用したトークン数と推定コストをステータスバーにリアルタイム表示。

## ⚡ クイックスタート

1. **インストール**: VS Code マーケットプレイスからインストール。
2. **API キー設定**: コマンドパレット (`Ctrl+Shift+P` / `Cmd+Shift+P`) $\rightarrow$ **Sakura AI Engine: API キーを設定** を実行し、トークンを入力。
3. **モデル選択**: Copilot Chat のモデルピッカーから `Sakura AI Engine` のモデルを選択。
4. **利用開始**: チャットで質問や指示を入力して、AI の力を体験してください。
