1# 使い方ガイド

このページでは、Sakura AI Engine for VS Code を使って Copilot Chat でチャットするまでの流れを説明します。

## 初回セットアップ

API キーを設定し、接続を確認するまでの流れです。

### Step 1: API キーを取得する
さくらのクラウドコントロールパネルから AI Engine の API トークンを発行してください。
- **形式**: `UUID:シークレット` (例: `12345678-1234...:abcdef...`)

### Step 2: API キーを VS Code に設定する
1. **操作**: コマンドパレット (`Ctrl+Shift+P` / `Cmd+Shift+P`) $\rightarrow$ **Sakura AI Engine: API キーを設定** を実行。
2. **入力**: 取得したトークンを貼り付けて Enter。
3. **結果**: 「Sakura AI Engine: API キーを設定しました」と通知され、API キーが暗号化されて保存されます。

### Step 3: 接続テストを行う（推奨）
1. **操作**: コマンドパレット $\rightarrow$ **Sakura AI Engine: 接続テスト** を実行。
2. **結果**: 接続に成功すると「接続に成功しました」と通知されます。
   - ※失敗した場合は、API キーの正しさや、`sakuraAiEngine.baseUrl` の設定を再確認してください。

## チャットで使う

### モデルを選択して質問する
1. **操作**: Copilot Chat パネルを開き、モデルピッカーから **Sakura AI Engine** のモデル（例: `preview/Kimi-K2.6`）を選択。
2. **入力**: チャット欄に質問を入力して送信。
3. **結果**: サーバーからストリーミング形式で回答が届き、逐次表示されます。

### 画像を添付して相談する (Vision)
1. **準備**: Vision 対応モデル（`preview/Kimi-K2.6` など）を選択。
2. **操作**: 画像ファイルをチャット欄にドラッグ＆ドロップ、または貼り付け。
3. **入力**: 「この画像のコードの間違いを指摘して」などの指示を入力し送信。
4. **結果**: AI が画像を解析し、視覚的な情報に基づいた回答を返します。

## 高度な機能を使う

### エージェントとして作業を依頼する (Tool Use)
1. **操作**: Copilot Chat のモードを **Agent** に切り替える。
2. **入力**: 「`src` フォルダ内の重複した関数を探して一つにまとめて」のように、具体的なタスクを依頼。
3. **結果**: AI が「ファイルの読み込み」や「書き換え」といったツールを自動で呼び出します。ユーザーは各操作に対して承認/却下を選択でき、最終的にコードが自動修正されます。

### 最新情報や深い推論を利用する (Responses API)
1. **準備**: `preview/Kimi-K2.6` または `preview/gemma-4-31B-it` を選択。
2. **入力**: 「今日の AI 業界の主要ニュースをまとめて」や「複雑な数学のパズル」を入力。
3. **結果**: 
   - **Web 検索**: AI が自動的に最新の Web 情報を検索し、ソース付きの回答を生成します。
   - **推論 (Reasoning)**: 思考プロセスを経て、より論理的に正しい回答を導き出します。

## 使用量とコストの管理

### リアルタイム確認
- **結果**: チャット応答完了後、ステータスバーに使用したトークン数と推定コスト（￥）が表示されます。

### 詳細なレポートを表示する
1. **操作**: コマンドパレット $\rightarrow$ **Sakura AI Engine: 使用量の詳細を表示** を実行。
2. **結果**: 現在のセッションおよび累積の使用量パネルが表示され、予算管理に役立てることができます。

## API キーの管理
- **削除方法**: コマンドパレット $\rightarrow$ **Sakura AI Engine: API キーを削除** を実行。
- **結果**: 保存されていた API キーが完全に削除され、以降の API リクエストは不可となります。
