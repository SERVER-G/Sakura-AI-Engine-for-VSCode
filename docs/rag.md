# RAG（ワークスペース検索）ガイド

RAG（Retrieval-Augmented Generation: 検索拡張生成）を使うと、Copilot Chat で質問した際に、ワークスペース内の関連コードを自動的に検索してチャットのコンテキストに追加できます。

## 仕組みの概要

1. **インデックス化**: ワークスペース内のソースコードを小さなチャンクに分割し、Embedding API でベクトル化してローカルに保存します
2. **検索**: チャットで質問すると、質問文と近い意味のコードチャンクをベクトル検索で探します
3. **コンテキスト追加**: 検索で見つかったコードをプロンプトに追加して、モデルに送信します

## 事前準備

RAG を使うには以下が必要です。

- API キーが設定済みであること
- ワークスペースがローカルディスク上にあること（Web 拡張は非対応）
- 対象のファイルが十分に小さく、Embedding API で処理できること

## セットアップ手順

### 1. ワークスペースをインデックス化する

1. コマンドパレットを開く（`Ctrl+Shift+P` / `Cmd+Shift+P`）
2. **Sakura AI Engine: ワークスペースをインデックス化** を実行
3. 進捗通知が表示され、ファイルの読み込み → チャンク分割 → Embedding 取得 → 保存 が順番に行われます
4. 「インデックス化が完了しました」と表示されたら完了

> 初回はワークスペースの規模によって数秒～数分かかることがあります。

### 2. RAG を有効にする

1. VS Code の設定を開く（`Ctrl+,` / `Cmd+,`）
2. `sakuraAiEngine.enableRag` を検索
3. **Sakura AI Engine: Enable Rag** にチェックを入れる

または `settings.json` に以下を追加します。

```json
{
  "sakuraAiEngine.enableRag": true
}
```

## チャットで使う

RAG を有効にすると、通常のチャットと同じように質問するだけで関連コードが自動追加されます。

```text
このプロジェクトの認証処理はどこに書かれている？
```

すると、ワークスペース内から認証に関係しそうな関数やクラスが検索され、モデルの入力に含まれます。モデルはそのコードを参照して回答します。

## インデックスの更新

ソースコードを大きく変更した場合や、新しいファイルを追加した場合は、再度インデックス化することをおすすめします。

1. コマンドパレットで **Sakura AI Engine: ワークスペースをインデックス化** を再実行
2. 古いインデックスは上書きされ、最新のコードで再構築されます

## インデックスをクリアする

RAG を使わなくなった場合や、インデックスを作り直したい場合は、コマンドパレットで **Sakura AI Engine: インデックスをクリア** を実行してください。ローカルに保存されたベクトルデータが削除されます。

## 注意事項

- RAG を有効にしても、インデックス化が済んでいない場合は通常のチャットと同じ動作になります
- 非常に大きなワークスペースの場合、インデックス化に時間がかかったり、Embedding API のコストが増えたりします
- 検索に含めたくないファイルは、`.gitignore` や VS Code の `files.exclude` 設定で除外すると効果的です
